# 字体来源与许可

本目录下的 woff2 均为开源字体(Variable Font 子集),按 SIL Open Font License 1.1 再分发:

| 文件 | 字体 | 许可 | 上游 |
|---|---|---|---|
| `SchibstedGrotesk.woff2` / `SchibstedGrotesk-Italic.woff2` | Schibsted Grotesk (Henning Skibbe / Schibsted) | OFL 1.1 | https://fonts.google.com/specimen/Schibsted+Grotesk |
| `JetBrainsMono.woff2` | JetBrains Mono (JetBrains) | OFL 1.1 | https://fonts.google.com/specimen/JetBrains+Mono |

选择这两款是因为它们是 Kimi Code 桌面端的界面字体,补丁目标即"让 ZCode 输出正文排版与 Kimi Code 一致"。

OFL 1.1 全文: https://openfontlicense.org
